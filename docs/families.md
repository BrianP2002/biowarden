# Task families

Each family builds paired workspaces from a seed: the **clean** twin and the **faulted** twin
share biology and task wording and differ only in the fact that triggers the trap; the truth is
never in the workspace. *Locus* is the layer where the error lives (data, tool default, user
statement, stale documentation, wrapper script). Generated by `tools/make_families_doc.py`.

Families by locus: data 25, documentation 7, task_statement 4, tool_default 65, wrapper 4; total 105.
